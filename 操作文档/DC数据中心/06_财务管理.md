# 财务管理

## 模块功能

财务管理模块提供财务相关报表的统一入口，以及研发工时数据的录入与异常监控功能：

- **报表**：财务相关数据对象的集中查看入口
- **研发工时**：研发人员工时数据录入，用于研发费用核算
- **工时异常**：工时分配异常的监控与查询，便于财务人员排查处理

## 页面关系

```
研发工时录入 → 数据保存 → 工时分配计算 → 异常识别 → 工时异常查询
     ↓                                              ↓
  数据存储                                    异常处理
     ↓                                              ↓
  费用核算 ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←← 异常修正
```

**联动流程**：

1. **研发工时录入**：财务人员录入各研发项目的工时分配数据
2. **数据保存**：系统将工时数据保存到数据库，并触发工时分配计算
3. **异常识别**：系统自动检测工时分配异常（如研发工时与实际分配不一致）
4. **工时异常查询**：财务人员在异常页面查看并处理异常数据
5. **异常修正**：修正异常后重新录入工时，确保费用核算数据准确

## 财务报表

### 页面作用

财务报表页面展示财务相关的数据对象列表，提供统一查看入口。这些数据对象是从 ERP 系统采集的财务数据，包括：

- 应收明细原始数据
- 应收结算清单
- 其他付款申请单
- 研发项目相关报表

### 操作流程

1. 在左侧菜单展开 **财务**，点击 **报表**

2. 通过筛选条件（表编码、表名称、启用状态、备注）查找目标报表

3. 点击操作栏按钮查看详情：

   - **日志**：查看数据刷新日志
   - **依赖树**：查看该报表的上游依赖对象

## 研发工时录入

### 页面作用

研发工时页面用于录入研发人员的工时分配数据，是研发费用核算的基础数据来源。

**核心功能**：

- 录入各研发项目的工时分配
- 记录研发工时占考勤工时比例
- 按项目分配工时明细

**数据用途**：

- 研发费用核算
- 项目成本分析
- 人员效率统计

### 操作流程

1. 在左侧菜单展开 **财务**，点击 **研发工时**

2. 点击 **加载** 按钮，加载当前已有的工时数据

3. 在表格中录入或修改工时数据

4. 点击 **保存** 提交数据

5. 点击 **重置** 清空未保存的修改

## 工时异常查询

### 页面作用

工时异常页面展示工时分配过程中发现的异常情况，便于财务人员排查处理，确保研发费用核算数据准确。

**异常来源**：

- 研发工时录入后，系统自动计算工时分配
- 系统检测到研发工时与实际分配不一致时，自动记录异常

**处理流程**：

1. 查看异常记录
2. 分析异常原因
3. 修正研发工时录入数据
4. 重新触发工时分配计算

### 操作流程

1. 在左侧菜单展开 **财务**，点击 **工时异常**

2. 通过筛选条件（年、月、工号、姓名、项目编码）定位异常记录

3. 查看异常详情，分析异常原因

4. 返回 **研发工时** 页面修正数据

### 常见异常类型

| 异常信息 | 原因说明 | 处理方式 |
|------|------|------|
| 无考勤记录，无法分配工时 | 员工在指定月份无考勤数据 | 确认考勤数据是否缺失 |
| 工时分配比例异常 | 实际分配工时与研发工时不匹配 | 调整工时分配比例 |
