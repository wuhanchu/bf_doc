# 销售管理

## 模块功能

销售管理模块提供销售数据的预估录入与数据可视化功能：

- **销售预估**：销售人员定期录入各客户分类（内销/外销）的销售预测数据
- **销售数据**：数据可视化报表，展示销售数据的同比分析

## 销售预估

### 功能说明

销售预估界面用于录入和管理销售预测数据，为生产计划制定提供参考依据。

### 操作流程

1. 在左侧菜单展开 **销售**，点击 **销售预估**

2. 点击 **加载** 按钮，加载当前已有的预估数据

3. 在表格中录入或修改预估数据

4. 点击 **保存** 提交数据

5. 点击 **重置** 清空未保存的修改

### 数据字段

| 字段 | 说明 |
|------|------|
| 年月 | 预测的评估月份，格式 YYYY-MM |
| 客户分类 | 内销 / 外销 |
| 字段编码 | 客户编码（关联 ERP 客户信息） |
| 预估类型字段 | 预估类型 |
| 盖型/客户 | 盖型或客户名称（内销） |
| 出口客户 | 出口客户名称（外销） |
| 开口 | 开口类型 |
| 品类 | 产品品类 |
| 子/分公司 | 子公司或分公司 |

**内销**：录入次月、次次月预测值，以及各客户的预测值

**外销**：录入各月份的预测值（如 1月、2月、...、2026年1月）

### 数据保存机制

- 保存时自动将相同「评估月份 + 客户分类」的历史数据标记为 `history = True`
- 新保存的数据作为当前有效预测值
- 保留历史数据供追溯分析

### 数据流程

```
销售预估录入 → market.market_sale_forecast 表 → daily.sale_forecast 视图
```

## 销售数据

### 功能说明

销售数据界面提供销售数据的可视化分析，包括销量统计、同比对比、维度切换等功能。

### 操作流程

1. 在左侧菜单展开 **报表**，点击 **销售数据**

2. 设置筛选条件：

   - **销售区域**：外销 / 内销
   - **组织**：全部 / 厦门 / 湖北
   - **日期范围**：选择起止月份

3. 查看数据指标：

   - **盖数**：当前期间销量总和
   - **同期盖数**：去年同期销量
   - **同比**：同比增长率

4. 切换分析维度：客户 / 部门 / 销售员

5. 查看图表展示，同比图例说明：

   - ≤-50%：同比下降超过 50%
   - -50%~0%：同比下降
   - 0%~50%：同比增长
   - ≥50%：同比增长超过 50%
