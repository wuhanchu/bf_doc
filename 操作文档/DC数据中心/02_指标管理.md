# 指标管理

## 模块功能

指标管理模块基于报表数据，按配置的计算公式和维度进行汇总计算，生成结构化的指标数据：

- **指标定义**：配置指标的计算公式、查询条件、时间维度、业务维度
- **指标计算**：支持合计、平均、除法等计算方式，自动生成指标数据
- **数据刷新**：支持全量刷新和增量刷新，定时任务自动更新指标数据
- **大屏展示**：指标数据供大屏展示和分析使用

## 核心概念

#### 指标类型与指标数据

| 概念 | 说明 | 存储位置 |
|------|------|----------|
| **指标类型** | 指标的定义：查询条件、维度、计算公式等配置 | 配置库 `conf.indicator_type` |
| **指标数据** | 指标的计算结果，按时间维度和业务维度组织 | 业务库 `report.indicator_data` |

#### 指标计算机制

- **计算方式**：系统将计算公式套在查询条件返回的数据上，按时间维度和业务维度分组计算
- **计算公式**：支持除法表达式（如 `a/b`），此时会额外记录各部分的明细值到「公式数据」列，展示为 `分子/分母` 形式
- **数据合并**：相同维度组合的指标数据重复生成时自动覆盖更新，不会产生重复数据
- **空值处理**：维度字段为空时统一显示为 `-`
- **年度汇总**：时间维度选择「年」时，月份列统一显示为「年合计」

### 数据流程

```
┌─────────────┐     ┌─────────────────┐     ┌─────────────┐
|   报表数据   │     |    指标类型配置   │     |   指标数据   |
| (_data 表)  |────▶| 查询条件+维度+公式 |────▶| (indicator_ |
└─────────────┘     └─────────────────┘     |    data)    |
                                            └─────────────┘
```

**流程说明**：

1. 指标类型通过查询条件从报表数据取数
2. 按时间维度、业务维度分组计算公式
3. 结果写入指标数据表，更新指标类型的刷新时间

## 标准流程

```
创建指标类型 → 生成指标数据 → 查看指标数据
```

### 步骤一：创建指标类型【必须】

> **步骤作用**：定义指标取数逻辑、维度和计算公式。
>
> **是否可选**：必须执行，是指标计算的基础。

1. 在左侧菜单展开 **指标**，点击 **指标类型**

2. 点击 **新建** 按钮，打开指标类型配置表单

3. 配置基本信息：

   | 字段 | 说明 |
   |------|------|
   | 指标名 | 指标的中文名称 |
   | 指标编码 | 指标唯一标识 |
   | 序号 | 展示排序 |
   | 单位 | 生成指标数据的单位 |

4. 配置取数与计算逻辑：

   | 字段 | 说明 |
   |------|------|
   | 查询条件 | 计算指标需要的查询数据（SELECT 语句） |
   | 增量条件 | 增量刷新时追加到查询条件后面的过滤条件 |
   | 时间维度 | 按时间分组的字段，多个用 `\|` 分隔（如年、月、班次日期） |
   | 业务维度 | 按业务分组的字段，多个用 `\|` 分隔（如组织、车间） |
   | 计算公式 | 根据查询数据计算的公式（如 `sum(quantity)` 或 `sum(a)/sum(b)`） |

5. 点击 **保存**

**查询条件示例**：

```sql
SELECT 
  org_id,
  shift_year,
  shift_month,
  quantity,
  defect_qty
FROM daily.production_data
WHERE org_id IS NOT NULL
```

> **说明**：查询条件返回的字段需包含时间维度、业务维度和计算公式中用到的字段

### 步骤二：生成指标数据【必须】

> **步骤作用**：执行指标计算，生成指标数据。
>
> **是否可选**：必须执行。

指标数据由定时任务按调度自动增量刷新，通常无需人工干预。

如需手动生成（如首次创建、数据修正后重算）：

1. 在指标类型列表中，找到目标指标

2. 根据需要点击操作栏中的执行按钮：

   | 按钮 | 说明 |
   |------|------|
   | 全量执行 | 删除该指标的全部旧数据，重新计算生成 |
   | 增量执行 | 按增量条件过滤，只计算新数据（默认定时任务方式） |

3. 执行完成后，列表的 **刷新时间** 列会更新为本次执行时间

> **说明**：
> - 全量执行会先清空该指标类型的所有指标数据，适用于维度调整、公式修改后的重算
> - 增量执行依赖配置的增量条件，相同维度组合的数据会自动覆盖更新

### 步骤三：查看指标数据【非必须】

> **步骤作用**：查看指标计算生成的结果数据。
>
> **是否可选**：本步骤为验证结果，非必须。

1. 在左侧菜单展开 **指标**，点击 **指标数据**

2. 通过筛选条件（指标类型等）定位目标指标

3. 查看指标数据：

   | 列 | 说明 |
   |------|------|
   | 公式数据 | 公式各部分的明细值（如 `分子/分母`），用于追溯计算过程 |
   | 数值 | 计算公式的最终结果 |
   | 维度列 | 时间维度和业务维度的具体值 |

4. 指标数据可通过以下方式查询：

   - **原始数据表**：`report.indicator_data` — 存储完整的指标数据，包含所有维度字段
   - **中文视图**：`report.indicator_data_cn` — 字段名转换为中文，组织编码转换为组织名称，适合直接查看和分析

## 常见操作

### 刷新上游依赖数据

指标计算依赖底层的报表数据，数据异常时可沿依赖链逐层刷新：

1. 在指标类型列表中，点击目标指标的 **依赖树** 按钮

2. 在依赖树列表中勾选需要刷新的上游数据对象（采集数据、中间数据、报表数据）

3. 点击 **刷新** 按钮，系统按依赖顺序依次刷新

4. 上游数据刷新完成后，再对该指标执行 **增量执行** 或 **全量执行**

### 修改指标定义

1. 在指标类型列表中，点击目标指标的 **修改** 按钮

2. 调整查询条件、维度或计算公式

3. 点击 **保存**

4. 修改维度或公式后，需执行 **全量执行** 重新生成数据（旧数据的维度结构可能已不匹配）

### 查看指标生成的数据

1. 在指标类型列表中，点击目标指标的 **数据** 按钮

2. 系统展示该指标类型下生成的指标数据，无需切换到指标数据界面筛选
