# LMS 物流管理系统 — 使用文档

LMS（Logistics Management System）是保沣集团的物流管理系统，覆盖**国内运输询报价**与**海外海运出运**两大业务：询价比价、订舱跟踪、上柜排载、费用预提与结算，并与金蝶 ERP 打通。

## 1. 系统简介

- **国内物流**：车队/拖车行在线询报价，多轮压价、自动比价选标，中标价格同步金蝶路线价目表
- **海外物流**：物流申请 → 海外询价 → 订舱委托 → 订舱底单上传 → 上柜计划/排车 → 费用预提 → 费用结算核对，全链路单据化跟踪
- **对外协同**：供应商（货代、托运）通过协同平台与微信公众号参与报价、接单、回填信息，全程线上化

## 4. 业务主线

### 4.1 国内主线

询价单（整车/零担）→ 发布询价轮次 → 供应商多轮报价 → 结束轮次自动比价（整车取线路+柜型最低底价；零担按 3 个重量区间分级）→ 确认/手动选标 → 发起审批（云之家）→ 审批通过同步金蝶路线价目表。

### 4.2 海外主线

物流申请（销售发起）→ 物流管理员审核 → 海外询价（货代按方案报价）→ 选价下单生成订舱委托 → 货代确认接单并上传订舱底单（船名/航次/截单时间等）→ 上柜计划与排车通知（拖车回填车辆司机，EIR 自动回传）→ 费用预提（按分摊规则生成预估费用）→ 费用结算（导入对账 → 核对 → 同步金蝶费用申请单）。
