# 保沣外贸协同平台（ECP）技术实现

> 仓库：`foreign-sale-backend`。.NET 6.0 + SqlSugar + BaoFeng.BFBase 自研框架的单体服务。

## 技术栈

- .NET 6.0（主项目 Portal），netstandard2.1（类库）
- SQL Server 2014+，数据库 QMS_Biz（与 QMS 共用，192.168.51.91）；K3 库 BAOFENG20171217（192.168.51.3）
- SqlSugar ORM，BaoFeng.BFBase.* 私有 NuGet 包系列
- Consul 服务发现、RabbitMQ（DotNetCore.CAP）、SignalR、JWT 认证

## 项目结构

```
ForeignSale.WebApi.Portal/  # 主 Web API 入口（.NET 6.0），控制器、Filters、Hubs
ForeignSale.App/            # 核心应用类库
ForeignSale.Domains/        # 领域层（业务逻辑，依赖 Services）
ForeignSale.Services/       # 服务实现
ForeignSale.IServices/      # 服务接口
ForeignSale.Entities*/      # 实体层
ThirdParty/                 # 第三方集成
```

依赖链：Portal → Domains → Services → IServices → Entities

## 认证链路（BFBase 体系）

1. `PortalController.Login()` → `PortalDomain.Login(username, password, companyName)` → 返回 JWT Token
2. JWT claims 包含：`UserId`、`Username`、`RoleId`、`DepartmentId`、`TargetId`、`TargetModule`
3. `JwtFilter`（继承 BFBase `AppAuthorizeHandler`）→ `JwtEncrypt.AutoRefreshToken()` 验证 + 自动续签 token
4. `PortalDomain.LoginedUser` / `Permeate.LoginedUser`（Domains/Extensions.cs:66）从 `UserId` claim 查 `SugarRepository<User>` 得到 User 实体，缓存到 `HttpContext.Items["LoginedUser"]`
5. `Program.cs` 中 `AddJwt<JwtFilter>(enableGlobalAuthorize: true)` 全局授权，`[AllowAnonymous]` 例外

### User 实体（BFBase.Entities.Authority，QMS_Biz dbo.[user]）

关键字段：`Id`、`Username`、`Name`、`EmployeeNumber`（员工工号，K3/外部系统桥接用）、`RoleId`、`DepartmentId`、`TargetId`、`TargetModule`。用户/角色/部门由 BFBase 框架管理。

## 关键机制

- **SignalR**（ChatHub）：连接时按 `RoleIds` claim 加入 `Role_{roleId}` 分组，服务端按角色推送文件审批等通知
- **CAP RabbitMQ**：`UserSubscriber` 接收 `EMPLOYEE.HANDOVER`（员工离职交接，业务数据换主），业务侧发布 `OUTSTOCK.UPDATE`
- **ActionLogger**：操作日志统一记录（含审计人姓名展示）
- **K3 同步**：装运订单/客户从 BAOFENG20171217 库读取，`EmployeeNumber` 关联 K3 销售员
- **Consul**：服务注册 `ECPServiceV2`，健康检查 `/consul/checkhealth`

## 用户查询的两种入口

- `Permeate.LoginedUser` — Domains 层用，静态属性
- `PortalDomain.LoginedUser` / `GetUsers(int[])` / `GetUsers("provider", id)` / `GetDepartmentUsers(id)` — 控制器层用，BFBase 封装的批量查询（约 65 处调用，用于名单显示与按角色/供应商通知）
