## 脚本

### md 转 PDF（`script/md2pdf.sh`）

把 Markdown 批量转换为 PDF，输出到 `export/` 文件夹，目录结构与源文件一致。

```bash
# 转换整个仓库
script/md2pdf.sh

# 转换指定文件夹
script/md2pdf.sh 操作文档/DC_数据中心

# 转换单个文件
script/md2pdf.sh 操作文档/公共操作/账号管理.md
```

说明：

- 依赖：pandoc（`brew install pandoc`）+ Google Chrome（本机路径，如不同改脚本头部 `CHROME` 变量）
- 图片等相对引用按源文件所在目录解析并内嵌进 PDF
- 输出位置：`export/<原相对路径>.pdf`（如 `操作文档/DC_数据中心/README.pdf`）；`export/` 为生成物，不入库
- 样式（A4、中文字体、表格边框、图片限宽）集中在脚本头部 `CSS` 变量，可按需调整
