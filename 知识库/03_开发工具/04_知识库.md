# WeKnora 知识库

## 基本信息

| 项目 | 说明 |
|------|------|
| 地址 | 见 [开发服务地址](../README.md#开发服务地址) |
| 用途 | 大模型驱动的企业级知识框架 |

## 核心功能

| 功能 | 说明 |
|------|------|
| RAG 检索增强生成 | 基于文档的智能问答 |
| ReAct 智能体 | 推理型 AI 问答 |
| Wiki 知识库 | 结构化知识管理 |
| 多模态文档解析 | 支持图片、表格等复杂文档 |
| 混合检索 | 向量检索 + 关键词检索 + 知识图谱 |

## 登录与账户

首次使用需创建账户：

1. 访问登录页面
2. 点击 **创建账户**
3. 填写邮箱和密码

## 知识库管理

### 创建知识库

1. 进入 **知识库** 模块
2. 点击 **新建知识库**
3. 配置：
   - 名称
   - 描述
   - 嵌入模型（向量模型）

### 上传文档

支持格式：PDF、Word、Markdown、TXT、Excel 等

1. 进入知识库
2. 点击 **上传文档**
3. 选择文件上传
4. 系统自动解析并建立索引

### 文档分段

上传后可调整文档分段策略：

- 按段落分段
- 按固定字数分段
- 自定义分段规则

## 智能问答

### RAG 问答

基于知识库内容的问答：

1. 选择目标知识库
2. 输入问题
3. 系统检索相关文档片段并生成回答
4. 显示引用来源

### ReAct 智能体

推理型问答，支持多步推理：

- 自动拆解复杂问题
- 多次检索和推理
- 适用于需要综合多个知识点的场景

```bash
curl -X POST "http://192.168.51.56:38100/api/v1/chat" \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{

    "question": "问题内容"
  }'
```

## 最佳实践

### 文档组织

- 按业务域创建不同知识库
- 文档命名清晰，便于识别
- 定期更新和清理过期内容

### 检索优化

- 选择合适的嵌入模型
- 调整分段大小（一般 500-1000 字）
- 为重要文档设置更高权重

### 权限管理

- 设置知识库访问权限
- 区分公开/内部/机密文档
- 按部门/角色分配访问权限
