# 桌面 AI（WorkBuddy）

## 解决什么问题

日常办公中的重复性工作——写文档、整理报表、处理会议纪要、分析数据——耗时且低价值。桌面 AI 助手把这些工作交给 AI 完成提升效率。

## 选择的软件

WorkBuddy 是腾讯提供的 AI 办公助手，保沣集团已开通使用，支持通过统一 API 接入公司 AI 额度（申请见 [AI 模型申请](03_AI模型申请.md)）。

## 主要功能

- **AI 对话助手**：问答、写作、翻译、总结等日常任务
- **Skill 技能**：针对具体场景（质检预审、报表处理、纪要整理）的自动化技能
- **多 Agent 并发**：复杂任务拆解并发执行（建站、数据分析等）
- **API 接入**：统一 API + token，可对接自研工具
