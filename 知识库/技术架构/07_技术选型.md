# 技术选型

新系统立项、新技术引入时的选型依据。原则上不超出下表范围，确需引入新技术需经信息部评估。

**当前主栈：React + Python (Flask) + PostgreSQL** —— 新系统默认按此组合立项。

## 选型原则

1. **延续性**：已有系统保持技术栈稳定，避免大规模重构
2. **标准化**：新系统统一技术栈，降低维护成本
3. **容器化**：所有自研服务优先容器化部署
4. **开源优先**：基础设施优先选用成熟开源方案
5. **可扩展**：架构支持水平扩展，应对业务增长

## 场景选型指南

### Web 管理系统（新系统默认场景）

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | React + Ant Design Pro | 自研系统主栈，新系统首选 |
| 前端（备选） | C#（ASP.NET） | 团队已熟悉的备选方案，适合与 .NET 生态集成的场景 |
| 后端 | Python + Flask | 基于 [flask_starter](10_开发模板.md) 模板开发（整合 flask_frame，含日志、监控、扩展与部署配置） |
| 数据库 | PostgreSQL | 主库默认选择，支持 Citus 分布式 |

> 前端框架 Vue 仅限旧项目继续运维，**新项目不允许使用**。

### 桌面应用

| 场景 | 选型 | 说明 |
|------|------|------|
| Windows 桌面应用 | C# + WebView2 | **默认方案**：界面用 Web 技术（HTML/JS），WebView2 内核承载，UI 与 Web 端复用 |
| Windows 桌面应用（备选） | WinForms | 简单工具类小窗口程序，无需复杂界面时选用 |

### 移动端 App

| 场景 | 选型 | 说明 |
|------|------|------|
| 跨平台 App | React Native | 与前端共享 React 技术栈，一套代码同时出 iOS / Android |
| 简单功能 | H5 页面 | 嵌入云之家/企微等已有 App，无需独立发版 |

### 简单页面

| 场景 | 选型 | 说明 |
|------|------|------|
| 活动页、报表页 | 原生 HTML | 单页面、无需工程化，直接部署 |

### 业务系统二开（存量延续）

| 场景 | 选型 | 说明 |
|------|------|------|
| MES / ERP / 金蝶定制 | C# + SQL Server | 跟随原厂技术栈，无选择余地 |

### 数据处理与 AI

| 场景 | 选型 | 说明 |
|------|------|------|
| 数据处理 / ETL | Python | Pandas、Airflow 生态 |
| AI 应用 / 模型调用 | Python | vLLM、Qdrant、WeKnora 生态 |
| 运维工具 / 脚本 | Python | 自动化运维首选 |

## 数据库选型

### 主库

| 优先级 | 数据库 | 场景 | 说明 |
|--------|--------|------|------|
| 1 | PostgreSQL | 新系统首选 | 主库默认选择，支持 Citus 分布式 |
| 2 | SQL Server | 存量延续 | MES、ERP 及已有项目主库 |

**原则**：新系统默认 PostgreSQL，业务系统延续 SQL Server。

### 补充数据库（不作主库）

| 数据库 | 场景 | 说明 |
|--------|------|------|
| Redis | 缓存 | 会话、缓存、消息队列 |
| Elasticsearch | 搜索 | 全文搜索、日志分析 |
| TDengine | 时序数据 | IoT、监控数据 |

**原则**：作为主库补充，按场景叠加，不单独作为主库。

## 中间件

| 组件 | 用途 | 说明 |
|------|------|------|
| Kong | API 网关 | 流量管理、认证、限流 |
| MinIO | 对象存储 | 文件、图片存储 |
| Redis | 缓存/消息 | 高性能缓存、消息队列 |
| RabbitMQ | 消息队列 | 异步任务、事件驱动 |

## 部署架构

**原则**：自研系统统一使用 Docker + K3s 容器化部署；仅特殊场景（如 .NET 历史系统）允许使用 IIS。

| 层级 | 技术 | 说明 |
|------|------|------|
| 虚拟化 | VMware | 底层资源池化 |
| 容器运行时 | Docker | 服务容器化封装 |
| 容器编排 | K3s | 轻量级 Kubernetes 集群 |
| CI/CD | Drone | 自动化构建部署 |
| 镜像仓库 | 腾讯云容器仓库 | 托管镜像存储 |
| 代码管理 | Gitea | 自托管 Git 服务 |
