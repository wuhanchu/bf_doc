# MinIO 对象存储

## 基本信息

| 项目 | 说明 |
|------|------|
| Console / API 地址 | 见 [开发服务地址](../Readme.md#开发服务地址) |
| 用途 | 公共文件/对象存储服务 |

MinIO 是高性能对象存储，兼容 Amazon S3 API。

## Console 操作

### 登录

访问 Console 地址，使用 Access Key 和 Secret Key 登录。

### 创建 Bucket

1. 左侧菜单点击 **Buckets**
2. 点击 **Create Bucket**
3. 输入 Bucket 名称
4. 配置访问策略（默认私有）

### 上传文件

1. 进入目标 Bucket
2. 点击 **Upload** 按钮
3. 选择文件或拖拽上传

### 设置公开访问

如需公开访问某个 Bucket：

1. 进入 Bucket → **Manage**
2. **Access Policy** 设为 **public**
3. 或使用 **Access Rules** 设置特定路径的访问规则

## mc 命令行工具

### 安装配置

```bash
# macOS
brew install minio/stable/mc

# 配置别名
mc alias set myminio http://192.168.51.91:9000 ACCESS_KEY SECRET_KEY
```

### 常用命令

```bash
# 列出所有 Bucket
mc ls myminio

# 创建 Bucket
mc mb myminio/mybucket

# 上传文件
mc cp local_file.txt myminio/mybucket/

# 上传目录
mc cp --recursive local_dir/ myminio/mybucket/

# 下载文件
mc cp myminio/mybucket/file.txt ./

# 删除文件
mc rm myminio/mybucket/file.txt

# 删除 Bucket
mc rb myminio/mybucket

# 设置公开访问
mc anonymous set download myminio/mybucket
```

## Python SDK (boto3)

```python
import boto3
from botocore.client import Config

# 创建客户端
s3 = boto3.client(
    's3',
    endpoint_url='http://192.168.51.91:9000',
    aws_access_key_id='ACCESS_KEY',
    aws_secret_access_key='SECRET_KEY',
    config=Config(signature_version='s3v4')
)

# 上传文件
s3.upload_file('local.txt', 'mybucket', 'remote.txt')

# 下载文件
s3.download_file('mybucket', 'remote.txt', 'local.txt')

# 列出文件
response = s3.list_objects_v2(Bucket='mybucket')
for obj in response.get('Contents', []):
    print(obj['Key'])

# 删除文件
s3.delete_object(Bucket='mybucket', Key='remote.txt')
```

## 预签名 URL

生成临时访问链接，无需暴露密钥：

```bash
# 使用 mc 生成分享链接（默认 7 天）
mc share download myminio/mybucket/file.txt

# 指定过期时间
mc share download --expire 3600 myminio/mybucket/file.txt
```

```python
# Python 生成预签名 URL
url = s3.generate_presigned_url(
    'get_object',
    Params={'Bucket': 'mybucket', 'Key': 'file.txt'},
    ExpiresIn=3600
)
print(url)
```
